# SQL baseline
app.sql and company.sql are independent executable SQLite initialization scripts. Apply once to new databases; runtime migrations must be versioned. Bootstrap administrator in Node using bcryptjs, never store plaintext password in SQL. Seed company profile/FY and opening balances through services. Default hike 5% is illustrative implementation default, configurable. All amounts integer paise and quantities integer hundredths of carat; rate and percent decimal strings validated in services. SQL constraints are intentionally not the full business engine: enforce cross-row allocation limits, party/category consistency, historical stock, date formats, exact loan settlement, sequence concurrency, posted immutability and reversal lifecycle in services. Reversed journal entries must remain in historical accounting with their offsetting reversal (do not exclude both inconsistently). Opening bills use open_items; payment and advance allocations reconcile to them. Journal source IDs are polymorphic and service-validated. Add indexes and migrations as implementation evolves. verify.py tests initialization and basic journal constraints only.
