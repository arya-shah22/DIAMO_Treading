# Technical architecture
Electron + electron-vite, React TypeScript, Node main process, better-sqlite3, Tailwind/shadcn, Lucide, React Router, Zustand, React Hook Form/Zod, TanStack Table, Recharts, decimal.js, date-fns, bcryptjs, PDFKit, ExcelJS, Vitest/Playwright, electron-builder. Pin compatible versions and lockfile. Bundle fonts/icons locally. No runtime network. Windows Program Files for binary, %APPDATA%/DIAMO_Treading for data; macOS /Applications and ~/Library/Application Support/DIAMO_Treading. Use Electron userData path. app.sqlite plus companies/<uuid>.sqlite, assets, logs. Create on first launch, migrations with pre-upgrade backup; never reset existing data.
Main services: auth, companies, masters, purchase, sale, inventory, payments, loans, accounting, cash-bank, reports, exports, backup, audit. Renderer pages call narrow typed preload APIs (auth.login/logout/changePassword, companies.list/create/switch, masters CRUD, purchase/sale preview/post/edit/cancel/list/detail, inventory.list/lots, payments.preview/post/edit/cancel, loans.create/interest/settle, journal.post, funds.transfer, reports.query/export, backup.configure/run/restore). Validate schemas and session/company in main; no arbitrary SQL/path IPC. Company switch invalidates cached state and closes prior DB safely. Single instance lock; foreign_keys ON, WAL, busy timeout; transaction boundaries cover sequence, postings, lots, allocations and audit. Use parameterized SQL; restrict file permissions; SQLite not encrypted by default. No secrets in logs. Password hash with bcrypt; bootstrap once. Session in main, lock/logout. Use integer-safe arithmetic and bounds.
Backup: SQLite online backup API, not raw live copy. Pause writes for coherent full backup; include app DB, company DBs, logos and manifest/checksums. User chooses folder, interval, retention, scope; daily + exit default, only running/on exit; catch missed schedule on next launch. Atomic temp file rename, verify integrity, log success/failure, warn inaccessible path. Restore validate archive paths, manifest/schema/checksums and integrity; pre-restore backup, close connections, stage replacement, rollback on failure, reopen/restart. Individual restore must register company without overwriting unrelated company; explicit confirmation. No backup deletion outside owned files.
Packaging: native dependency rebuild per target, Windows x64 EXE, macOS Intel/ARM DMG; test on respective OS, document signing/notarization and prerequisites. Development may use internet for packages; installed app offline. Source layout src/main/{database,ipc,repositories,services}, src/preload, src/renderer/src/{pages,components,layouts,stores}, src/shared/{types,schemas,calculations}, tests/{unit,integration,e2e}, resources. SQL baseline is not a substitute for migrations or service invariants.
